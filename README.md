# Inspeqa

The desktop API client that keeps your data on your computer.

Download the latest version from [Releases](https://github.com/Inspeqa/inspeqa-releases/releases/latest) or from [inspeqa.com](https://inspeqa.com).

- **Windows:** `Inspeqa_x64-setup.exe`
- **Linux (Debian or Ubuntu):** `Inspeqa_amd64.deb`

This repository holds installers only. It has no source code.
